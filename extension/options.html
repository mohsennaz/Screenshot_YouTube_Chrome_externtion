Setup Instructions:

  1. Create a bot using @BotFather and copy the token
  2. Create a Telegram channel or use an existing one
  3. Add your bot as an administrator to the channel
  4. Get the channel ID using @getidsbot
  5. Paste both token and chat ID above
  6. Click the "Auto" button on any YouTube video to start
